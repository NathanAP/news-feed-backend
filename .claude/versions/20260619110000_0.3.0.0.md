# v0.3.0.0 — Database + users table

## What was done
Set up the database layer with migrations and the users table.

- Configured goose v3 for SQL migrations, embedded into the binary via `embed.FS`.
- Created migration `20260619120000_create_users_table.sql` with full up/down.
- Created `schema.sql` (clean schema without goose markers, used by sqlc).
- Configured `sqlc.yaml` and generated type-safe Go code in `sqlc/`.
- Created `sqlc/queries/users.sql` with: CreateUser, FindUserByID, FindUserByGoogleID, UpdateUserLastLogin, SoftDeleteUser.
- Created `services/controllers/users.go` with business logic layer wrapping the sqlc queries.
- Created `schemas/users.go` as placeholder for future user DTOs.

## Key decisions
- Used `modernc.org/sqlite` (pure Go, no CGO) instead of mattn/go-sqlite3 for Windows compatibility.
- Goose was chosen over golang-migrate due to better compatibility with the pure-Go SQLite driver.
- UUIDs use v7 (`github.com/google/uuid`).
- Soft delete pattern: `status=0`, `removed_at=CURRENT_TIMESTAMP`, `modified_at=CURRENT_TIMESTAMP`.
