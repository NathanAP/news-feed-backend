# Versão 0.21.3.0 — saída HTML básica + sanitização (bluemonday)

**Data:** 2026-07-01

## O que foi feito

- **Tratamento agora sai em HTML básico** (antes Markdown): o prompt pede apenas
  `<p>/<strong>/<em>/<ul>/<ol>/<li>/<blockquote>/<h2..h4>`, sem links, imagens, wrappers
  (`html/body/head`) nem `class/style`.
- **Etapa de sanitização (`services/sanitize`)** com **bluemonday**, aplicada como decorator no
  `Treater` (vale pra CRON e pra dry-run). Garante a whitelist **independente do que o modelo
  cuspir** — é a defesa real contra XSS, já que o LLM não é confiável pra enforçar isso.
- **Política customizada (NÃO `UGCPolicy`).** A `UGCPolicy` do bluemonday **permite** `<a>`, `<img>`
  e URLs, o que **contraria** a regra do projeto ("sem URLs / sem a / sem img"). Então montamos uma
  política própria: só as tags básicas, **sem atributos** (mata `class`/`style`), sem links/imagens.
  `SkipElementsContent` em `script/style/head/title/noscript/iframe` pra o conteúdo deles não vazar
  como texto quando um documento HTML inteiro chega do modelo.

## Respostas às dúvidas do planejamento

- **HTML inteiro (com `<html>`/`<body>`) chega problema?** Não. O bluemonday remove os wrappers e
  mantém o conteúdo do corpo; `head`/`script`/`style` são descartados junto com o conteúdo. Testado.
- **`UGCPolicy` é a correta?** Não, pelo motivo acima — trocada por política customizada.
- **Doc:** corrigido o typo "Sanatização" → "Sanitização" e a nota sobre a política.
