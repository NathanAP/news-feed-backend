# v0.7.0.0 — Debug logger

## What was done
Created a global debug helper controlled by `VERBOSE_MODE` and added route logging to all existing endpoints.

### New package: `logger/logger.go`
- `type Color int` with constants: `ColorBlue` (default), `ColorGreen`, `ColorRed`, `ColorYellow`, `ColorCyan`, `ColorWhite` — backed by ANSI escape codes.
- `func Setup()` — must be called once in `main.go` after `godotenv.Load()`. Reads `VERBOSE_MODE` from env and sets the global `enabled` flag.
- `func Log(message any, color ...Color)` — prints to stdout when enabled. Handles `string`, `error`, and any complex type via `fmt.Sprintf("%+v", v)`. Color is optional (defaults to blue).
- `func RouteStart(path string)` — logs `@@@ ROUTE START - {path} - {timestamp} @@@` in yellow.
- `func RouteEnd(path string)` — logs `@@@ ROUTE END - {path} - {timestamp} @@@` in yellow.

### Updated: `main.go`
- `logger.Setup()` called immediately after `godotenv.Load()`.
- Health check route (`GET /v1/health`) now logs RouteStart/RouteEnd.

### Updated: all 7 endpoint handlers
Added `logger.RouteStart(c.Path())` + `defer logger.RouteEnd(c.Path())` to:
- `auth/google.go`, `auth/callback.go`, `auth/refresh.go`, `auth/logout.go`
- `auth/invalidate.go`, `auth/invalidate_all.go`
- `users/me.go`

## Key decisions
- `Setup()` instead of `init()`: `init()` runs before `godotenv.Load()`, so `VERBOSE_MODE` would always be unset. Explicit `Setup()` guarantees correct env var reading.
- No external library needed: ANSI codes are plain string constants, formatting uses standard `fmt`.
- This is a **debug helper**, not observability. Observability is a separate future concern in a different package.
- Tests unaffected: `VERBOSE_MODE` is not set in test environments, so `enabled=false` and all `Log` calls are no-ops.
