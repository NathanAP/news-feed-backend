# Versão 0.11.0.0 — Sources

**Data:** 2026-06-25

## Resumo

Implementação completa do domínio de fontes de notícias (`sources`). Fontes são globais (sem user_id), gerenciadas por administradores (atualmente abertas a qualquer usuário autenticado enquanto não há sistema de admin). A descoberta automática de RSS usa uma estratégia em duas camadas com validação via `gofeed`.

## O que foi feito

- `services/rss/discovery.go` — lógica de descoberta em duas camadas:

    3. Validação de cada candidato com `gofeed.Parser.Parse(reader)`

## Decisões de design

- **Filtros de lista em Go** (não SQL): fontes são admin-managed e em número limitado; evita queries dinâmicas com sqlc
- **`url_rss` obrigatório no create**: a rota `rss_discovery` existe exatamente para facilitar esse preenchimento
- **Soft delete com find-before-delete**: garante 404 explícito ao tentar deletar fonte inexistente (sem esse passo, `SoftDeleteSource` com ID inválido seria silencioso)
- **RSS discovery retorna 200 com lista vazia**: conforme convenção de endpoints de busca que não encontram resultados
