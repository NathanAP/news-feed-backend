# Versão 0.36.1.0 — Twitch embed toca (parent reescrito para o host do CLIENT_URL)

**Data:** 2026-07-14

Patch da 0.36. O Claude do projeto do **web client** notou (via `api-integration.md`) que o embed do
Twitch **renderizava mas não reproduzia**. Correto: o player do Twitch só toca quando o parâmetro
`parent` do `src` bate com o **domínio que renderiza** (proteção anti-clickjacking). O RSS traz o
`parent` da **fonte** (ou nenhum), então no nosso client o `parent` nunca batia.

**Decisão (com o Nathan): a API reescreve o `parent`** — coerente com o link interno absoluto
(`CLIENT_URL`) que já usamos; o conteúdo "já vem pronto" para o client configurado.

## O que mudou

- `services/embedtreatment.Treat` passou a receber o `CLIENT_URL`. Além de converter Instagram → link,
  agora **reescreve o `parent` do iframe do Twitch** (`player.twitch.tv` / `clips.twitch.tv`) para o
  **host do `CLIENT_URL`** (via `url.Parse(...).Hostname()`, **sem porta** — ex.: `http://localhost:5173`
  → `parent=localhost`; `https://app.example.com` → `parent=app.example.com`). Força um único `parent`
  correto (dropa os existentes) e **preserva os demais params** (`video`/`channel`/`clip`/...).
- Roda **antes** do sanitize (o sanitize mantém o iframe pela allowlist de `src`, que casa qualquer query).
- **Pulado sem `CLIENT_URL`** (embed fica como veio). **YouTube** não precisa e é deixado intacto.
- Wire: `processor` (CRON) e dry-run `POST /articles/treatment` passam o `CLIENT_URL` ao `Treat`.

## Testes

- `services/embedtreatment/embedtreatment_test.go`: parent reescrito (params preservados); host sem
  porta (`localhost`, não `localhost:5173`); clip do Twitch reescrito; YouTube e outros iframes
  intactos; sem `CLIENT_URL` → inalterado. Testes de Instagram atualizados para a nova assinatura.
- Verificado empiricamente (embed + sanitize): `parent=app.example.com`, `video` preservado, `class`/
  `style` removidos, iframe mantido.
- `go build`, `go vet`, `gofmt -l`, `go test ./...` — **verdes** (suíte completa).

## Docs

`.claude/memory/api-integration.md` (o client agora sabe que o `parent` já vem certo, e o que fazer se
rodar em outro domínio), `PROJECT.md` (nota na whitelist de embeds), `memory/overview.md`,
`memory/endpoints.md`, `rules/structure.md`. ROADMAP com 0.36.0.1 (doc do client) e 0.36.1.0.

## Como testar

`POST /v1/articles/treatment` (com `CLIENT_URL` setada) e um `content` com
`<iframe src="https://player.twitch.tv/?video=123&parent=algumdominio.com">`: a resposta traz o `src`
com `parent=<host do CLIENT_URL>`. Sirva o client nesse mesmo host → o Twitch reproduz.
