# v0.6.0.0 — Taskfile + integration tests + E2E tests

## What was done
Added task automation, integration tests with real DB, and end-to-end tests.

### Taskfile.yaml
Cross-platform task runner replacing Makefile (works natively on Windows PowerShell, Linux, and macOS).

Commands available (each has a long alias and a short alias):
- `task local-start` / `task ls` — builds binary and starts locally in background (PID file management).
- `task local-down` / `task ld` — stops the local process via PID file.
- `task local-restart` / `task lr` — stop + start.
- `task docker-start` / `task ds` — `docker-compose up -d`.
- `task docker-down` / `task dd` — `docker-compose down`.
- `task docker-restart` / `task dr` — `docker-compose restart`.
- `task docker-prune` / `task dp` — down + volumes + system prune.
- `task build` / `task b` — compiles binary to `./tmp/`.
- `task sqlc-generate` / `task sg` — runs `sqlc generate`.
- `task vet-all` / `task va` — runs `go vet ./...`.
- `task test-units` / `task tu` — unit tests.
- `task test-integration` / `task ti` — integration tests.
- `task test-end-to-end` / `task te2e` — E2E tests.
- `task test-all` / `task ta` — all three test suites in sequence.
- `task help` / `task` — lists all available tasks.

### Shared test utilities
- `tests/utils/db.go` — `SetupTestDB(t)`: opens in-memory SQLite, runs goose migrations, registers cleanup. Uses `runtime.Caller` to locate the migrations directory robustly.

### Integration tests (tests/integration/api/)
Real DB (in-memory SQLite with migrations) + real controllers + MockGoogleOAuth for OAuth2.
Added `TestMain` to load `.env` before the integration suite runs.

**auth/** — 13 tests covering:
- Callback: creates user, updates last_login on re-login, missing code, OAuth failure.
- OAuth config: validates `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URL` are set.
- Refresh: returns new access_token, unknown token, missing body.
- Logout: revokes refresh_token (verified by subsequent refresh failure), unauthenticated.
- Invalidate: revokes specific token, missing ID.
- Invalidate-all: revokes all user tokens, missing user_id.

**users/** — 3 tests covering:
- /me with valid token and real user in DB.
- /me with revoked session (refresh_token_id not in DB).
- /me unauthenticated.

### E2E tests (tests/end-to-end/api/)
Real DB + real controllers + MockGoogleOAuth only. Covers full sequential flows.

**auth/** — 13 tests covering:
- Callback success, missing code, OAuth failure.
- Full login → refresh → logout flow (verifies session invalidation).
- Single session policy (second login invalidates first refresh_token).
- Protected route: no token, invalid token, malformed auth header.
- Route not found (404).
- Refresh: missing body, invalid token.
- Invalidate-all: missing user_id.
- Invalidate: missing body.

### Version files
Created `.claude/versions/` with summary files for all versions from 0.1.0.0 to 0.6.0.0.

## Key decisions
- Integration test DB uses `:memory:` SQLite — each test gets a fresh isolated DB.
- E2E `seedSession()` helper bypasses the Google OAuth flow entirely to set up authenticated state, consistent with the E2E convention of creating a real refresh_token in the DB directly.
- `TestMain` in integration auth package loads `.env` so `TestOAuthConfig_Integration_RequiredEnvVarsPresent` can verify the variables are set.
- Taskfile uses platform conditionals for local start/stop to support both Windows and Unix.
