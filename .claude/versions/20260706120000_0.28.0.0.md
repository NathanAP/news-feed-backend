# Versão 0.28.0.0 — atualização de dependências + reorganização do `structure.md`

**Data:** 2026-07-06

Fase 1 da 0.28: as duas tarefas de manutenção/docs de baixo risco. A **revisão** (terceiro item
planejado da 0.28) roda em seguida como fase própria e seus eventuais fixes sobem patch
(`0.28.1.0`+), conforme as regras de revisão.

## 1. Atualização de dependências (escopo conservador)

Decisão de escopo: subir apenas as dependências **diretas** desatualizadas do `go.mod`, deixando o
`go mod tidy` resolver as indiretas que as acompanham. O `go list -u -m all` mostrava uma lista enorme
de pendências (clickhouse, ydb, mssqldb, pgx, opentelemetry, etc.), mas são **drivers opcionais que o
`goose` arrasta como indiretas** e que o projeto não usa — puxá-las com `go get -u ./...` incharia o
grafo sem ganho e com risco. As `golang.org/x/*` são indiretas e subiram sozinhas no tidy.

Bumps aplicados:
- `github.com/gofiber/fiber/v2` v2.52.13 → **v2.52.14** (patch)
- `github.com/pressly/goose/v3` v3.27.1 → **v3.27.2** (patch)
- `modernc.org/sqlite` v1.52.0 → **v1.53.0** (minor)

Indiretas que acompanharam (via `go mod tidy`): `golang.org/x/crypto` v0.52.0, `x/net` v0.55.0,
`x/sync` v0.21.0, `x/sys` v0.45.0, `x/text` v0.37.0, `modernc.org/libc` v1.73.4.

Verificação: diff do `go.mod` limpo (só os 3 diretos + indiretas esperadas, **nenhum** driver do goose
entrou). `go vet ./...`, `go build ./...` e a suíte completa (`go test ./...`) passaram — verde.

> Fora de escopo (registro para o futuro): `fiber/v2` está em manutenção (existe `v3`, com breaking
> changes). Migrar para o v3 merece uma versão dedicada, não um bump de rotina.

## 2. Reorganização do `structure.md`

Reescrito o bloco de árvore em `.claude/rules/structure.md` conforme pedido: agora mostra **apenas a
hierarquia de pastas com uma descrição em parênteses** (`├── bruno (coleção de requisições ...)`),
sem os `arquivo.extensão` de exemplo e sem os `...`.

Além do novo formato, a árvore foi **atualizada para a estrutura real de hoje**, que já divergia do
exemplo antigo. Passaram a aparecer/corrigir:
- `schemas/enums`, `services/judgement`, `services/langdetect`, `services/pagination`,
  `services/discovery`, `services/ai/{gemini,openaicompat}`, `cmd/seed`.
- Em `tests/`: `integration/{cron,discovery}` (fora de `api/`), `mocks/{external,repositories,services}`
  e `utils`.
- Texto de introdução ajustado (não fala mais em "exemplos de arquivos").

## Testes

Suíte completa executada após o bump — todos os pacotes verdes (unit, integração, e2e, e os pacotes
de lógica pura `langdetect`/`sanitize`/`pagination`). Nenhuma mudança de contrato de rota, então Bruno
e testes não precisaram de alteração além de rodarem.

## Como testar

- `task va` (vet) e `task ta` (suíte completa) devem passar com as libs novas.
- `git diff go.mod go.sum` deve mostrar somente os 3 bumps diretos + as indiretas esperadas.
- Abrir `.claude/rules/structure.md` e conferir que a árvore reflete as pastas atuais no formato novo.
