# Versão 0.13.0.0 — Articles

**Data:** 2026-06-26

## Resumo

Implementação do domínio de notícias (`articles`). Articles são **globais** (sem `user_id`): são descobertos de fontes globais e, no futuro (0.15), tagueados pela IA e julgados nos feeds dos usuários. Nesta versão são criados/editados manualmente (rotas que no futuro serão exclusivas de administradores; servem agora para semear dados até o cron existir).

## Decisões de design

- **`url_original` único entre ativos** (decisão confirmada): índice único parcial, evita notícias duplicadas e prepara o terreno para o cron da 0.15. Recriação após soft-delete é permitida.
- **DELETE incluído** (decisão confirmada): soft delete com find-before-delete para 404 explícito.
- **Rota de redirecionamento adiada** (decisão confirmada): não faz parte desta versão.
- **Keywords como JSON TEXT**: serializadas no controller; a `ArticleResponse` devolve `[]string`.
- **Sem `user_id`**: articles são globais; o vínculo com usuário acontece via `articles_feeds` na 0.14.
- **Sem `mark-as-read`**: depende de `articles_feeds`, portanto fica na 0.14.
