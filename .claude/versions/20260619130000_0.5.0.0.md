# v0.5.0.0 — Unit tests + interface refactoring

## What was done
Extracted controller interfaces for testability and wrote the first unit test suite.

### Refactoring
- Added `emit_interface: true` to `sqlc.yaml` → sqlc now generates `db.Querier` interface automatically.
- Updated `UserController` and `RefreshTokenController` constructors to accept `db.Querier` instead of `*sql.DB`.
- Extracted `OAuth2Provider` interface from `*oauth2.Config` (handles Exchange and Client methods).
- Created `services/controllers/interfaces.go` with: `OAuth2Provider`, `UserControllerInterface`, `RefreshTokenControllerInterface`, `AuthControllerInterface`.
- Updated all endpoint functions to accept controller interfaces instead of concrete types.
- Updated `middlewares/auth.go` to accept `RefreshTokenControllerInterface`.
- Updated `main.go` to construct `db.New(database)` (Querier) and pass it to controllers.

### Mocks
- `tests/mocks/external/google_oauth.go` — simulates Google OAuth2 exchange and userinfo response.
- `tests/mocks/repositories/users_repository.go` — testify mock implementing `db.Querier` for user queries.
- `tests/mocks/repositories/refresh_tokens_repository.go` — testify mock implementing `db.Querier` for refresh token queries.
- `tests/mocks/services/jwt.go` — generates test access tokens with a known test secret.

### Fixtures
- `tests/fixtures/user_fixtures.go` — `NewTestUser()`, `NewTestUserWithoutPicture()`.
- `tests/fixtures/refresh_token_fixtures.go` — `NewTestRefreshToken()`, `NewExpiredTestRefreshToken()`.

### Unit tests (21 tests, all passing)
- `tests/unit/auth/` — google, callback, refresh, logout, invalidate, invalidate_all.
- `tests/unit/users/` — me.

## Key decisions
- Mock controllers are defined inline in the test packages (simple structs with function fields).
- Unit tests use `app.Test()` from Fiber — no real DB, no real external services.
- All tests guard against running in production/staging via `ENVIRONMENT` check.
